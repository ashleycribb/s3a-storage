# Prompts for Antigravity

Dave (Grok Bot) writes numbered prompt files here. Ashley tells Antigravity: "do prompts/NNN-name.md".

## Rules for Antigravity
1. Do exactly what the prompt file says. Don't widen scope.
2. When finished, append an entry to `prompts/LOG.md` (newest at the bottom) using the template there.
3. Commit the work and the log entry together. Do not push or tag unless the prompt says to.
4. If blocked, write the blocker in the log entry with status `blocked` and stop.
5. Never edit a prompt file after it's written; Dave adds a new one instead.
