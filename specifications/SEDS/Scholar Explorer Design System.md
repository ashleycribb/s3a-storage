# SEDS — Scholar Explorer Design System

**Specification Identifier:** SECS-SEDS-1.0.0  
**Status:** Canonical Reference Specification  
**Version:** 1.0.0  
**Target Audience:** Frontend Architects, UX/UI Designers, React Engineers, Academic Collaborators  

---

## 1. Product Philosophy

### Mission
Scholar Explorer is an open scientific research platform engineered to empower doctoral researchers, domain experts, and scholars to discover, synthesize, and verify complex literature with mathematical rigor and epistemic transparency.

### Core Design Principles
1. **Research-First Philosophy**:
   - The primary citizen of the user interface is the **evidence**, not the chat prompt.
   - Interfaces prioritize dense, high-signal spatial and relational overviews (3D topic clusters, citation graphs, synthesis matrices) over endless textual chatter.
2. **Human-First AI**:
   - AI agents propose, locate, extract, and draft; **humans decide, verify, steer, and certify**.
   - Autonomous agents must pause at high-stakes epistemic checkpoints (Human-in-the-Loop Gating) rather than making unchecked assertions.
3. **Evidence Before Generation**:
   - No synthesis statement or literature claim may be presented to the researcher without an explicit, verifiable anchor (DOI, line span, or cryptographic content hash).
   - The platform rewards abstention ("Evidence inconclusive") over confident hallucination.

## 2. Information Architecture & Navigation

The platform organizes research around an active **ResearchProject** containing a persistent **Workspace**:

```
                       PROJECT WORKSPACE
┌─────────────────────────────────────────────────────────────┐
│ Header: Project Selector • Search Ribbon • Snapshot Export  │
├───────────────────┬─────────────────────────────────────────┤
│ DISCOVER (Left)   │ SYNTHESIZE & VERIFY (Right)             │
│ • Literature Feed │ • 3D Cluster Scatter Plot (Spatial)     │
│ • Filter & Facets │ • Synthesis Matrix (Comparative Claims) │
│ • Paper Cards     │ • Knowledge Graph (Inter-Paper Links)   │
│ • Local Vault     │ • Provenance Audit Ribbon (Human vs AI) │
└───────────────────┴─────────────────────────────────────────┘
```

### Progressive Disclosure Model
- **Level 1: Scanning**: High-level Paper Cards displaying title, authors, publication venue, year, citation velocity, and 3D topic centroid.
- **Level 2: Inspection**: Detailed drawer displaying methodology summary, extracted core claims, and direct open-access PDF links.
- **Level 3: Deep Verification**: Full evidence graph showing supporting, contradicting, and contextual passages linked to the exact text offsets.

## 3. Visual Language & Design Tokens

### Typography
- **Display & Headings**: Inter or Newsreader Serif (for authoritative, academic feel).
- **Body & Data**: Inter (`font-sans`), optimized for high-density reading.
- **Code, Hashes & DOIs**: JetBrains Mono or Fira Code (`font-mono`).

### Color Tokens (Epistemic State Palette)
Colors convey epistemic status rather than arbitrary styling:
- **Verified / Ground Truth**: `emerald-600` (`#059669`) / Dark: `emerald-400` (`#34d399`)
- **Contradiction / Mismatch**: `rose-600` (`#e11d48`) / Dark: `rose-400` (`#fb7185`)
- **Under Human Review / Awaiting Gating**: `amber-500` (`#f59e0b`) / Dark: `amber-400` (`#fbbf24`)
- **AI Hypothesis / Unverified**: `sky-600` (`#0284c7`) / Dark: `sky-400` (`#38bdf8`)
- **Background & Canvas**: Neutral slate (`#0f172a` in dark mode; `#f8fafc` in light mode).

## 4. Canonical Components Contract

### 1. Paper Card (`PaperCard.tsx`)
- Displays title, authors, DOI link, year, and badge indicators.
- Must show citation count and Open Access status.
- Includes actions: *Add to Workspace*, *Inspect Claims*, *Open PDF*.

### 2. Evidence Card (`EvidenceCard.tsx`)
- Renders an extracted empirical assertion.
- Shows source paper DOI, exact quote excerpt, and extraction confidence score.
- Displays relation toggle: `[Supports]` | `[Contradicts]` | `[Contextual]`.

### 3. Claim Card (`ClaimCard.tsx`)
- Synthesized assertion generated by the researcher or agent.
- Features a **Verification Badge** showing percentage of supporting evidence.
- Flags any known prior hallucinations or methodological anomalies.

### 4. 3D Topic Cluster Plot (`ClusterScatterPlot.tsx`)
- Visualizes the research corpus projected along the S3A 3D Skilling Hilbert curve coordinates ($X, Y, Z$).
- Interactive camera controls (rotate, zoom, pan) with tooltip inspection of paper nodes.

### 5. Snapshot Dialog (`SnapshotDialog.tsx`)
- Facilitates the export and import of `.snapshot.s3a` research containers.
- Shows manifest preview: Project UUID, Work count, Claim count, Checksum, and File size.

## 5. Approved Terminology Standard

To preserve academic integrity and eliminate confusing tech jargon, all user-facing interfaces must adhere to this terminology dictionary:

| Approved Term (USE) | Prohibited Term (AVOID) | Rationale |
| :--- | :--- | :--- |
| **Discover Sources** | Federated Search | Focuses on researcher intent rather than networking mechanics. |
| **Research Workspace** | Selection Queue / Cart | Reinforces scholarly workbench rather than e-commerce metaphor. |
| **Export Snapshot** | Save / Export Package | Emphasizes deterministic, point-in-time state capture. |
| **Continue in Local Lab** | Handoff / Sync to Desktop | Clear distinction between cloud exploration and local execution. |
| **Research Assistant** | AI Source Scout / Bot | Dignifies the tool as a scholarly co-pilot. |
| **Evidence Verified** | AI Approved / 100% True | Avoids dangerous overclaiming of automated truth. |
| **Methodological Note** | Warning / Error Code | Frames feedback academically. |

## 6. Accessibility & Responsive Design

- **WCAG 2.1 AA Compliance**: Minimum 4.5:1 contrast ratio across all epistemic badges and text.
- **Keyboard Traversal**: Full navigation of literature lists, evidence cards, and workspace controls using `Tab`, `Arrow`, `Enter`, and `Esc`.
- **Responsive Layouts**:
  - **Desktop (>= 1280px)**: Multi-column panoramic workbench (Discover + 3D Cluster + Synthesis Matrix).
  - **Tablet (768px - 1279px)**: Split-pane drawer with collapsible discovery sidebar.
  - **Browser Extension (360px - 480px)**: Compact Clipper drawer focusing on active tab metadata capture.
